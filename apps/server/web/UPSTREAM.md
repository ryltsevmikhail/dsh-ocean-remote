# Происхождение серверного интерфейса Ocean

До коммита c683bd1 интерфейс использовал компоненты, стили и изображения из локального `deepseek-harness-server/web/src`. Публичный источник, ревизия и отдельное подтверждение лицензии в исходном описании не приводились.

В Ocean этот интерфейс заменён минимальной реализацией входа и списка устройств: main.tsx, api.ts, ocean.css и index.html написаны заново для форка. Заимствованные компоненты, theme.tsx, upstream.css/selfhost.css и изображения из public удалены из текущего дерева. Ant Design и его иконки больше не являются прямыми зависимостями серверного приложения.

Новая реализация использует существующий HTTP API без изменений серверной авторизации или протокола. Не содержит логотипов DeepSeek, внешних шрифтов и скопированных графических ресурсов. Тема следует системной настройке, интерфейс — на русском. Новый код распространяется под корневой MIT-лицензией форка.

Это устраняет выявленный риск в текущей серверной веб-сборке, но не удостоверяет права на исторические коммиты и не заменяет аудит зависимостей, базовых образов и других клиентов.
