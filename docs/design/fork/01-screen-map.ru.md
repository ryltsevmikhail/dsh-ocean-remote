# Карта экранов и контента (UX-01)

Статус: черновик для согласования. Реализация — после утверждения пользователем. Термины: **Host** — машина с DSH, **Client** — подключающаяся, **аккаунт Ocean** — серверная принадлежность, **ключ** — подтверждённый SHA-256 пира, **соединение** — Noise-канал.

## Подписи: текущие и целевые

Часть подписей сейчас английская (локали `en`/`zh`, панель доверия и консоль — русские), часть — жёстко зашита по-русски. В этой карте русские подписи — **целевые**; текущие строки указаны для сверки.

| Сейчас | Целевое |
| --- | --- |
| «Remote» (кнопка футера, aria «Remote») | «Remote» (термин) |
| «Ключи» / aria «Доверие устройств» | «Ключи» / «Доверие устройств» |
| «Settings» / «Remote settings» | «Настройка» / «Настройка Remote» |
| «Connection lost» / «Connect again» | «Соединение потеряно» / «Подключиться снова» |
| «Доверие устройствам — SHA-256» | сохранить |
| «Host — ключ принимающей стороны» / «Client — ключ подключающейся стороны» | сохранить |

## Что принадлежит форку, а что native

| Поверхность | Владелец | Можно менять |
| --- | --- | --- |
| Список сессий, чат, композер, workspace-браузер, настройки моделей | native DSH | Нет: только стилизация через слоты и наши панели рядом |
| Кнопки футера «Remote», «Ключи», «Настройка» | форк | Да |
| Карточка «Настройка Remote», панель «Ключи» | форк | Да |
| Строка подключения и уведомления (слои, обрыв, повтор) | форк | Да |
| Консоль Ocean: вход, устройства, отзыв | форк | Да |
| Диагностика и её копирование | форк | Да |

## Плагин: карта

```
Футер (native shell)
└─ «Remote» ────────────────► карточка Remote (наш modal)
   ├─ [локальный режим]  кнопка входа/подключения, список Host'ов, «Добавить workspace»
   ├─ [подключение]      слои: аккаунт · ключ · транспорт, прогресс, «Повторить»
   ├─ [обрыв]            «Connection lost», номер попытки, «Connect again»
   ├─ [ошибка]           причина, безопасный код, следующее действие
   └─ [не авторизован]   форма входа Ocean (server URL, логин, пароль)
└─ «Ключи» ─────────────────► панель доверия
   ├─ собственный SHA Host-роли (подписан ролью)
   ├─ собственный SHA Client-роли
   ├─ ожидающие запросы: роль, ID, generation, полный SHA, подтверждение
   └─ сохранённые ключи: provenance, «Снять доверие»
└─ «Настройка» ─────────────► карточка настроек
   ├─ роль (Host/Client) и сервер
   ├─ «Разрешить управление этим устройством»
   ├─ вход Host: аккаунт/пароль либо код регистрации
   ├─ подключение: статус, «Переподключить», «Выйти»
   ├─ терминал и ACP-бэкенды (конфигурируемы; по умолчанию выключены)
   ├─ предпросмотр портов
   ├─ диагностика: «Скопировать диагностику» + поле снимка
   └─ аккаунт и Device ID (только чтение)
```

## Ocean: карта

```
/app/login ─────────► вход (аккаунт сервера)
/app/remote ────────► список устройств
   ├─ пусто: «Пока ни одного устройства» + как подключить
   ├─ строка: имя, статус, роль, платформа, версии, «Отозвать»
   └─ ошибка: доступ/сессия, повтор
```

## Согласованные правила содержания

- Один смысл — один термин: «аккаунт», «ключ», «соединение», «сессия», «устройство».
- Роли подписаны всегда: «Host на другой машине», «Client на этой машине».
- Полный SHA-256 показывается целиком, без сокращений; короткий префикс — только в диагностике и там явно подписан.
- Опасные действия называют объект и последствие: «Снять доверие с ocean-stage5-host — следующее подключение потребует нового подтверждения».
- Никакого «всё в порядке», если проверка не пройдена: неподтверждённый ключ, недоступный транспорт и истёкшая сессия видны отдельными строками.

## Что остаётся native намеренно

Список сессий, история, чат, композер, выбор модели, workspace-браузер внутри сессии, настройки плагинов DSH. Мы не строим второй экран сессии: это раздвоило бы историю.
