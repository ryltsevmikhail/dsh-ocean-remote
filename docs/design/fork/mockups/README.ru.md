# Макеты форка (этап 06, для согласования)

Статус: **черновик визуального направления**, показывается пользователю до переделки интерфейса. Согласование этих макетов не означает автоматического согласия на весь дизайн: направление обсуждается отдельно (спецификация 06).

## Что показано

| Макет | Состояние | Файл |
| --- | --- | --- |
| Карточка Remote, desktop 1440 | Подключено + уведомление о потере связи с автопоповтором | `remote-card-desktop.png` |

| Узкий экран 360 | Те же карточки столбцом | `remote-card-narrow.png` |

Исходник разметки: `remote-card.html` (самодостаточный, без внешних ассетов и шрифтов).

## Что проверено по макету

- Полный SHA-256 переносится и **не обрезается** ни на 1440, ни на 360.
- Опасное действие окрашено в danger и подписано объектом; legacy не зелёный.
- Чекбокс независимой сверки **не предзаполнен**.
- Слои «аккаунт / ключ / транспорт» показаны раздельно.
- Нет горизонтального скролла страницы на 360.

## Чего в макетах нет

- Тёмная тема проверена, светлая — нет (макет только тёмный).
- Контраст не измерялся автоматически; значения выбраны по целевым AA.
- Экраны консоли Ocean и настройки здесь не показаны — они появятся в следующей итерации после согласования направления.
