## Чего ещё нет (дефекты объёма)

- **Макеты desktop и узкого экрана сделаны** для двух экранов: [карточка Remote и панель «Ключи»](mockups/README.ru.md) (1440 и 360). Экраны настроек и консоли Ocean — следующая итерация после согласования направления.
- Токены вынесены не полностью: плагин использует native-темы, у консоли Ocean свои переменные; часть семантических токенов (успех/предупреждение/опасность) ещё не введена.
- Контраст палитры консоли Ocean проверяется автоматически (`pnpm check:contrast`, шаг CI, 26 пар). Поверхности плагина на токенах native DSH этим не покрыты. Адаптив макетов проверяется скриптом `pnpm check:mockups` (360/768/1440, `--write-shots` перегенерирует PNG; без Playwright шаг падает, а не пропускается молча); живой интерфейс — по-прежнему глазами.
- **Лицензии ассетов:** в `packages/plugin/src/client/icons.ts` лежат base64-PNG иконок сторонних вендоров без указания источника и лицензии; `THIRD_PARTY_NOTICES` покрывает только серверные зависимости. Нужно либо задокументировать, либо заменить своими SVG (задача шага 1).
- Темы: поддержка светлой/тёмной темы native DSH **не проверялась** аудитом.
