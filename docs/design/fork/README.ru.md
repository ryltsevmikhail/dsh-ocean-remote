# Дизайн форка (этап 06)

Статус: **ожидает согласования пользователем** до масштабной переделки интерфейса. Спецификация: [06-design](../../specs/06-design.ru.md).

Документы:

1. [Карта экранов и контента](01-screen-map.ru.md) — что принадлежит форку, что остаётся native.
2. [Wireframes](02-wireframes.ru.md) — setup → trust → connect → session, revoke и восстановление, матрица состояний.
3. [UI kit](03-ui-kit.ru.md) — токены, компоненты, доступность, контраст, ассеты и лицензии.
4. [План замены](04-replacement-plan.ru.md) — малые проверяемые шаги.

## Что уже есть в коде

Функциональные поверхности, которые предстоит привести к системе: кнопки футера, карточка «Настройка Remote», панель «Ключи», строка подключения со слоями, уведомление об обрыве, диагностика, консоль Ocean.

## Чего ещё нет

- Токены вынесены не полностью: плагин частично использует native-темы, консоль Ocean — свои переменные.
- Нет скриншот-проверок контраста и адаптива в автоматизации.
- Макеты для согласования (desktop и узкий экран) — следующий артефакт после ответа пользователя.
