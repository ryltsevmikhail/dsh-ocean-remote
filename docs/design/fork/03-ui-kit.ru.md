# UI kit: токены, компоненты, состояния (UX-02, UX-09, UX-11)

Статус: черновик. Часть токенов уже используется плагином (взяты из темы native DSH через `--dsw-alias-*`), часть — собственная для консоли Ocean.

## Токены

Две группы: **существующие** (уже используются в коде — имена сверены с `packages/plugin/src/client/shell.ts` и `apps/server/web/src/ocean.css`) и **предлагаемые** (вводятся на шаге 1 плана, помечены явно).

| Смысл | Плагин: существующий токен | Смысл | Ocean: существующий токен |
| --- | --- | --- | --- |
| Фон поверхности | `--dsw-alias-bg-layer-1` / `-2` / `-3` | Фон поверхности | `--surface` |
| Основной текст | `--dsw-alias-label-primary` | Основной текст | `--ink` |
| Второстепенный текст | `--dsw-alias-label-secondary` / `-tertiary` / `-dimmed` | Второстепенный текст | `--muted` |
| Граница | `--dsw-alias-border-l1` … `-l4` | Граница | `--border` |
| Акцент | `--dsw-alias-brand-primary` | Акцент | `--accent` / `--button` |
| Наведение | `--dsw-alias-interactive-bg-hover` | Подложка | `--wash` |
| Успех | `--dsw-alias-state-success-primary` | Успех | **нет** → предлагается `--success` |
| Предупреждение | `--dsw-alias-state-warn-primary` / `-warn-label` | Предупреждение | **нет** → предлагается `--warning` |
| Ошибка/опасность | `--dsw-alias-state-danger-primary`, `--dsw-alias-state-error-primary` | Ошибка | **нет** → предлагается `--danger` |
| Моноширинный (SHA, ID) | `--dsw-alias-font-mono` | — | `monospace` |
| Фокус | задан плагином (`:focus-visible`, 2px акцент + offset) | Фокус | `:focus-visible` на акценте |

Правила:

- Семантические имена, а не hex по месту. Новые цвета добавляются парами для светлой и тёмной темы.
- Предлагаемые токены Ocean (`--success`, `--warning`, `--danger`) пока не существуют: сейчас в консоли только `--surface`, `--ink`, `--muted`, `--border`, `--accent`, `--button`, `--wash`. Их ввод — шаг 1.

## Компоненты

| Компонент | Где | Обязательные состояния |
| --- | --- | --- |
| Кнопка | обе поверхности | default, hover, focus-visible, disabled, busy, danger |
| Поле ввода | setup, доверие, SHA | default, focus, invalid, disabled, readonly |
| Карточка | устройства, настройки | default, selected, stale, error |
| Диалог | карточка Remote, доверие, подтверждение | open, trap-фокус, Escape, focus return |
| Уведомление | строка подключения, обрыв | info, warning, danger, success |
| Бейдж | роль, статус, provenance | neutral, info, success, warning, danger |
| Строка состояния | слои аккаунт/ключ/транспорт | ok, required, conflict, none |

## Правила контента

- Заголовки — существительными: «Доверие устройствам», «Ваши устройства».
- Кнопка называет действие: «Снять доверие», «Отозвать», «Connect again»; не «ОК».
- Ошибка: что случилось → почему безопасно показать код → что сделать.
- Опасность не рисуется зелёным, legacy не получает зелёный бейдж, «всё хорошо» не показывается до проверки.

## Доступность и масштаб

- Контраст: текст ≥ 4.5:1, крупный ≥ 3:1, границы контролов и фокус ≥ 3:1.
- **Проверяется автоматически:** палитра консоли Ocean в обеих темах — 26 пар (текст и нетекстовые границы/фокус) через `pnpm check:contrast` в CI. Для границ контролов введён отдельный токен `--border-strong` (3:1), `--border` остаётся декоративным разделителем.
- **Не проверяется автоматически:** поверхности плагина, которые берут цвета из native-темы DSH (`--dsw-alias-*`) — их значения приходят извне и в этом репозитории не измеряются.
- Клавиатура: все действия достижимы Tab, диалоги удерживают фокус и возвращают его на кнопку-источник.
- Скринридер: значимые асинхронные исходы объявляются через `role="status"` / `aria-live="polite"`, ошибки — `role="alert"`.
- Длинные строки (SHA-256, ID) переносятся `overflow-wrap:anywhere`, без обрезки и без «…» в середине.
- Масштаб 200% и ширины 360 / 768 / 1440: без горизонтальной прокрутки страницы, submit и закрытие всегда доступны.
- Reduced motion: анимации отключаются через `prefers-reduced-motion`.

## Ассеты и лицензии

- Иконки интерфейса: собственные SVG-примитивы (компьютер, ключ, стрелка), без сторонних наборов; лицензия репозитория MIT.
- **Открытый вопрос:** в `packages/plugin/src/client/icons.ts` есть base64-PNG иконок сторонних вендоров без источника/лицензии; `THIRD_PARTY_NOTICES` покрывает только серверные зависимости. Нужно документировать или заменить (шаг 1).
- Шрифты: системные, без загрузки внешних файлов.
- Никаких upstream-ассетов и логотипов, кроме явно лицензированных зависимостей в `THIRD_PARTY_NOTICES`.

## Темы и язык

- Темы: берём те, что реально включает native DSH; отдельная «своя» тема не вводится. Фактический набор тем **не проверялся** — проверка входит в шаг 8 плана.
- Язык новых сценариев — русский; english/中文 остаются для строк, которые уже переводятся, без смешивания трёх языков в одном сообщении.
