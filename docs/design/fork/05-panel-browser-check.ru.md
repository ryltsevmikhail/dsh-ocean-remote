# Проверка рендера настроек и доверия — 20 октября 2026

## Стенд и граница доказательства

Изолированный Chromium 156, временный HTTP-сервер на `127.0.0.1`, новый browser context без пользовательских данных. Отрисованы **настоящие** `createRemotePluginOptions` (`view: page`), `createPeerTrustPanel` и `installStyle`; ответы control и значения theme aliases — синтетические. Профили, данные и ключи рабочего DSH не использовались. Модель не вызывалась. Собственные браузер и HTTP-сервер остановлены.

Это browser-render smoke, **не** проверка внутри native оболочки DSH, реального approval lifecycle, screen reader или настоящий browser zoom 200 %. Он не закрывает соответствующие критерии этапов 03–06.

## Матрица

Две поверхности × light/dark × ширины 360, 640, 768, 1440 CSS px; высота 900 px — **16 комбинаций**. Данные: длинные собственные/pending/trusted/expired Device ID, полный SHA-256 из 64 символов, длинный origin, сохранённый ключ и запросы обеих ролей. Настройки с авторизованным синтетическим аккаунтом; details агентских настроек раскрывались кликом.

| Проверка | До исправления | После исправления |
| --- | --- | --- |
| Ширина документа на 360 / 640 / 768 / 1440 | 1700 / 1700 / 1700 / 1700 | 360 / 640 / 768 / 1440 |
| Сохранённый Device ID | Не переносился, растягивал документ | Полный текст переносится, без обрезки |
| SHA input после Shift+Tab → Tab | `:focus-visible`, но `outline: none` | `solid 2px`, цвет акцента в обеих темах, 16/16 |
| Refresh после Tab | Видимый outline 2px | Видимый outline 2px |
| Card/chevron при reduced motion | Переход 160 ms | Переход 0 ms |
| Ошибки страницы | 0 | 0 |

После `scrollIntoView` проверены прямоугольник и попадание центра каждого из **280 показанных controls** (24 на настройки и 11 на отдельную панель, по 8 комбинаций): все доступны в viewport. Скрытая карточная шапка режима `page` не считается показанным control. Длинное значение input прокручивается внутри самого поля — это не переполнение страницы и не обрезка показываемого полного SHA в тексте.

Approve изначально отключён; checkbox + точный полный SHA включают кнопку. Синтетический отказ операции показывает alert; отдельное уведомление об истечении не содержит действий подтверждения. Это проверка UI на синтетическом ответе, не реальный пяти­минутный прогон очереди. TTL/cooldown, атомарная проекция и запрет старой generation отдельно защищены core-тестами.
