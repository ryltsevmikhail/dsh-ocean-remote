## Что автоматизировано

| Команда | Покрывает |
| --- | --- |
| `pnpm check:contrast` | 36 пар цветов консоли Ocean в двух темах: текст, состояния (успех/предупреждение/опасность), границы контролов и фокус |
| `pnpm check:mockups` | макеты на 360/768/1440/720/705 px: нет горизонтального скролла, SHA не обрезан, доступные имена, видимый фокус, цели ≥ 32×32 px, отсутствие CSS-анимации при `prefers-reduced-motion` |
| `pnpm -r test` | полный текущий набор: 842 теста в 9 пакетах, Plugin 502; повторён в рабочем checkout. Исторический чистый клон `02f40c4` — 840 тестов, это отдельное доказательство ([проверка релиза](../../release-check.ru.md)) |

Ограничения автоматики: `check:mockups` проверяет уменьшенные ширину и высоту окна (450 px), **не настоящий browser zoom**, и видит лишь CSS-анимации, существующие на момент загрузки; переходы и анимации из JS им не покрыты. Реальный zoom подтверждён отдельным `chrome.tabs.getZoom/setZoom` прогоном, а reduced-motion transition поля консоли — `check:console`. Без Playwright эти скрипты падают, а не пропускаются молча.

## Что остаётся ручным

- Согласование визуального направления пользователем (UX-AC5).
- Полный ручной проход по всем состояниям и actual screen reader; не путать с уже выполненными native DOM/keyboard и выборочным визуальным smoke.
- Двухмашинные сценарии (обрыв, отзыв, смена ключа) — сеть bigpc доступна, но SSH-аутентификация не завершена.
