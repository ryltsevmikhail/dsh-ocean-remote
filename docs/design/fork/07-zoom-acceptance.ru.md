# Настоящий browser zoom 200 % — 20 октября 2026

## Метод и изоляция

Настоящий DSH `0.2.0-rc.2` и текущая сборка плагина, новый приватный Chromium context, новые HOME/DSH_HOME/XDG_*/CODEX_HOME и workspace. Рабочий DSH и браузер пользователя не использовались. В DSH-прогоне модель, вход в Ocean и remote-сессия не запускались; терминал и агентские бэкенды выключены, сервер — недоступный loopback.

Zoom изменён **настоящим `chrome.tabs.setZoom`** через временное MV3-расширение только в новом browser context. `getZoom` подтвердил **1 → 2**. Не использовались CSS zoom, setViewport, device emulation или `Emulation.setPageScaleFactor`.

| Метрика | 100 % | 200 % |
| --- | --- | --- |
| Размер окна outer | 1440×1000 | 1440×1000 |
| Размер inner | 1440×913 | 720×456 |
| DPR | 1 | 2 |
| visualViewport.scale | 1 | 1 |
| screen / avail screen | 800×600 | 800×600 |

Это **headless Chromium**: screen — синтетическая метрика, не физический монитор. Проверяется реальный browser zoom в изолированном браузере, а не пользовательский headed-сеанс.

## Проверенный срез

Light/Dark переключались настоящими настройками Appearance в DSH. Открыты обе footer-панели — настройки и доверие: **4 комбинации при 200 %**.

- Документ: scrollWidth = innerWidth = 720 во всех случаях. Диалог: clientWidth = scrollWidth = 678, края 20/700 CSS px; горизонтального переполнения нет.
- По два собственных SHA-256 на случай: **8/8** имеют 64 uppercase hex символа, DOM Range внутри горизонтальных границ, ellipsis отсутствует. Соседние 36-символьные code — Device ID, а не усечённый SHA.
- После настоящего Refresh и окончания обновления выполнены 45 Shift+Tab и 45 Tab на случай: **360/360** внутри диалога, не BODY, с solid outline.
- Escape закрывает и возвращает фокус на исходную кнопку: **4/4**.
- Нижние действия настроек доступны при прокрутке. Header close/refresh **не sticky** и при прокрутке вниз уходят за верх viewport; фокусирование и scrollIntoView возвращают их в видимую область: **8/8**, enabled/focused. Нажатие Close отдельно не принималось — закрытие проверено через Escape.

Первый отдельный прогон дал обрезанные Playwright screenshots 720×456; **они не считаются визуальным доказательством**. Прогон повторён в ещё одном новом профиле: native CDP `Page.captureScreenshot` без clip дал корректные снимки 1440×913. Визуально просмотрены низ настроек Light и низ доверия Dark; остальные результаты — DOM/keyboard измерения, не полный ручной просмотр всех состояний.

## Консоль Ocean при настоящем 200 %

Отдельный свежий локальный Ocean из production build, явные синтетические account/password, временный state, loopback, новые HOME/DSH_HOME/XDG_*/CODEX_HOME и persistent Chromium profile. Это не развёрнутый Ocean и не пользовательские credentials. Zoom также установлен временным MV3 `chrome.tabs`: **1 → 2**, inner **1440×913 → 720×456**, DPR **1 → 2**, outer остаётся **1440×1000**. Темы Ocean выбраны через media preference Light/Dark в Playwright; это эмуляция темы, **не подмена zoom**.

Выполнен один реальный локальный проход: login → регистрация двух синтетических устройств через API → настоящий control WebSocket `hello`/`hello.ack` → refresh → измерения Light/Dark → отзыв обоих устройств → logout. Всё при zoom 2; модель и сторонние API не использовались. Вместо настоящего плагина работают синтетические API-устройства и control socket, поэтому remote-plugin E2E этим не подтверждается.

- В обеих темах горизонтальный overflow документа — 0; таблица clientWidth/scrollWidth **670/670**, caption полностью сообщает «1 из 2 устройств онлайн».
- Tab после refresh: «Выйти» → регион «Список устройств» → отзыв online → отзыв offline; outline **2/3/2/2 px**. Сам регион таблицы целиком **не помещается по высоте viewport** — нельзя заявлять, что каждый его прямоугольник в viewport. Отдельные действия обеих строк доступны после прокрутки; первые/последние revoke controls помещаются в viewport.
- Оба отзыва и logout успешно завершились в этом локальном проходе; ошибок страницы — 0.
- Снимки native CDP без clip имеют размер **1440×913**; light/dark таблица и light overview просмотрены визуально. Это не полный ручной или screen-reader аудит.

Собственные browser и сервер завершены. Токены/cookies/ключи не публиковались; рабочий DSH и пользовательский браузер не использовались.

## Границы и очистка

- Это отдельная UX-09 zoom-проверка, не полная a11y-приёмка и не actual screen reader.
- В DSH-панелях не проверены pending/legacy/changed-key, confirm/reject/revoke или Ocean auth. Локальная консоль отдельно проверена в описанном выше положительном проходе; негативы auth/revoke при 200 % целиком не принимались. Модель, история, инструменты и двухмашинный E2E не проверены.
- Оба собственных browser contexts и runtime process groups завершены; проверка по отдельным рабочим каталогам не нашла оставшихся собственных процессов. Bootstrap URL и stdout обрабатывались только в памяти и не публиковались, секретные файлы не читались.
- Вместе с [native проверкой ширин и focus trap](06-native-panel-check.ru.md) это закрывает измерения показанных панелей на указанных viewport/zoom, но не остальные требования этапа 06.
