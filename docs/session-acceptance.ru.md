# Приёмка удалённой сессии (этап 03, часть 1)

Проверено на двух реальных машинах: Host на bigpc, Client на ноутбуке, каждый в отдельном изолированном профиле, собственный Ocean по приватному Tailscale HTTPS, `forceRelay`. **Модель не вызывалась** — согласование на реальный запрос ещё не получено, поэтому проверена только часть сценария, не требующая генерации.

## Что подтверждено

| Сценарий | Результат |
| --- | --- |
| Подключение из интерфейса | «Connected · Relay», слои «Account: signed in» и «Key: trusted» |
| Открытие удалённого workspace | Выбор строки и «Open workspace» перевели интерфейс в удалённый workspace |
| Заголовок и контекст | В шапке — имя Host `ocean-stage5-host` и «Exit»; в composer — модель `DeepSeek-V41-Flash`, режим `Workspace Write`, метка `Remote` |
| Создание сессии без запроса | Кнопка «New Session» создала сессию: состояние «No sessions yet» исчезло, ошибок страницы 0 |
| Перезагрузка страницы | После reload интерфейс остался в удалённом workspace, сессия доступна (нет «No sessions yet») |
| Ошибки браузера | 0 на всех шагах |

Удалённый workspace открывается в нативном интерфейсе DSH: список сессий, composer и выбор модели приходят с Host, локальная история не подставляется.

## Что не проверено и требует согласования

- Отправка запроса и ответ модели, streaming, стоимость.
- Остановка генерации.
- Чтение файла инструментом и подтверждение tool-действия.
- Запись файла.
- Продолжение той же сессии после перезагрузки с проверкой идентификатора и истории (сейчас подтверждено только, что сессия переживает reload).
- Ошибки провайдера (нет ключа, лимит, таймаут).
- Два Client одновременно.

Эти пункты нельзя закрыть без реального вызова модели: нужен согласованный провайдер, лимит и разрешённые инструменты.

## Условия и границы

Изолированные профили созданы отдельно от рабочего DSH; его данные, ключи и модели не использовались. Тестовые процессы остановлены, launch-токены удалены. Провайдер модели в тестовых профилях не настраивался — интерфейс показывает модель Host, но запрос не отправлялся.
