# Проверка лицензий DSH Ocean Remote

Дата: 2026-10-19. База: `69efa04a5d617b3ba5d38f806f9bb9dcf9f95de3`, версия манифестов 0.5.13.
Это техническая инвентаризация, не юридическое заключение и не подтверждение готовности всех сборок к распространению.

## Собственный код upstream

Корневой package.json объявляет MIT. packages/plugin/LICENSE и apps/vscode/LICENSE содержат одинаковый текст с Copyright (c) 2026 DSH Remote contributors. README upstream указывает на лицензию плагина как лицензию проекта. В корень форка добавлена точная копия этого текста без замены правообладателя. Это не устраняет вопросы о правах на сторонние заимствования.

MIT позволяет дорабатывать, переименовывать, распространять и продавать копии, не обязывая открывать изменения. Нужно сохранять уведомление об авторских правах и разрешении. Лицензии зависимостей действуют отдельно; названия, логотипы и товарные знаки не становятся нашими.

## Заимствованные материалы

- Иконки Android: docs/official-menu-icons.md фиксирует источник DeepSeek Harness, ревизию и полный MIT-текст с Copyright (c) 2026 DeepSeek. Сохранить этот текст; при упаковке APK обеспечить его включение в распространяемые уведомления, а не только ссылку на репозиторий.
- Серверный интерфейс: исходное описание указывало на локальный deepseek-harness-server/web/src без публичной ревизии и лицензии. На этапе 2 Ocean заимствованные компоненты, стили, тема и изображения удалены из текущего дерева и заменены минимальным заново написанным интерфейсом. См. apps/server/web/UPSTREAM.md. Это устраняет конкретное заимствование в новой веб-сборке, но не подтверждает права на историю Git и не является юридической гарантией для всего репозитория.
- Необязательный Intelligent UI renderer: docs/intelligent-ui-android.md фиксирует внешний источник и commit bfb6b35f7ee94291629796d2b5eb577d20d8fa29. Лицензия на этом commit проверена: MIT, Copyright (c) 2026 dreamfarer-space. Источник: https://github.com/dreamfarer-space/deepseek-harness-intelligent-ui/blob/bfb6b35f7ee94291629796d2b5eb577d20d8fa29/LICENSE . При включении renderer в APK необходимо включить полный текст лицензии и проверить его собственные встроенные зависимости. Локальная необязательность renderer не означает его отсутствия в CI/release: upstream описывает строгий вариант APK с renderer.

## Зависимости: ограниченная инвентаризация

Проверены 11 package.json и 11 importer lockfile pnpm v9. В lockfile: 1130 записей packages и 1164 snapshots; license-полей нет, integrity присутствует. Спецификаторы dependencies/devDependencies/optionalDependencies в манифестах совпадают с importer lockfile.

Для 84 уникальных внешних прямых name@locked-version получены npm metadata: заявлены MIT, ISC, BSD-2-Clause или Apache-2.0; отсутствующих деклараций и copyleft среди этой выборки не обнаружено. В том числе прямые пакеты @deepseek-ai и @lukeburns/clatterjs@1.0.0 декларируют MIT. Это проверка деклараций прямых зависимостей, а не прочтение лицензий всех tarball и не проверка всей транзитивной цепочки. Apache-2.0 может требовать сохранения NOTICE, если он есть в распространяемом пакете.

Дополнительно выборочно проверены npm metadata 23 транзитивных name@version (всего 107 внешних пакетов). Особенности: node-forge@1.4.0 объявляет (BSD-3-Clause OR GPL-2.0), то есть допустим выбор BSD-3-Clause, а GPL не обязательна; caniuse-lite@1.0.30001809 — CC-BY-4.0, требуется соблюдение условий атрибуции; argparse@2.0.1 — Python-2.0; spdx-license-ids@3.0.23 — CC0-1.0. Выборочные npm-декларации canvas и wrtc не заменяют проверку встроенных WebRTC/Skia и нативных third-party notices. Остальные примерно 1023 записи packages по лицензиям не проверены; охват не является полным аудитом.

## Перед публикацией

1. Серверную веб-сборку выпускать только из дерева после замены заимствованного интерфейса; исторические сборки этой заменой не очищены.
2. Составить полный version-pinned список транзитивных зависимостей для конкретных артефактов, включая optional/native и зависимости внешнего renderer.
3. Проверить полные LICENSE/NOTICE распространяемых пакетов: npm metadata недостаточно.
4. Включить соответствующие тексты в npm/VSIX/APK/образ и проверить содержимое готовых архивов. Корневая LICENSE не заменяет уведомления о включённых сторонних библиотеках.
5. Проверить отдельно базовый Docker-образ, нативные Android/WebRTC-компоненты, шрифты, изображения и другие ресурсы.

Во время первоначальной инвентаризации ничего не устанавливалось и не развёртывалось. При последующих этапах зависимости для локальной проверки устанавливаются только в клон форка с отключёнными install-скриптами; это не установка плагина в работающий DSH. Проверка не подтверждает безопасность программы или совместимость с установленным DSH. Имена npm-пакетов и внутренние идентификаторы пока сохранены, чтобы не ломать сборку и установку; новый пакет под именем upstream публиковать нельзя.
