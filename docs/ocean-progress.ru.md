# Этапы Ocean: проверки и ревью

## Этап 1 — явный сервер (c683bd1)

Удалены fallback сервиса автора из плагина, TUI, CLI и install patch. Сохранённые адреса не стираются. Сборка и типы плагина, 396 тестов, проверка bundle и независимое read-only ревью прошли. Другие клиенты пока не адаптированы.

## Этап 2 — независимый серверный интерфейс

Удалены старые компоненты, тема, стили, три графических ресурса и зависимости Ant Design. Новый интерфейс написан для Ocean на React/CSS: вход, ручное обновление списка устройств, выход. По замечанию пользователя переработаны типографика, палитра, форма входа и мобильная компоновка; сохранены системная тема и отсутствие внешних графических/шрифтовых ресурсов.

Первое независимое ревью выявило: /app/remote не обслуживался при обновлении; login response сохранял лишний token в React state; после auth-перехода терялся фокус; китайская инструкция описывала удалённую страницу. Все замечания исправлены. В браузерной проверке обнаружен также отказ входной HTML-страницы при навигации с cross-site metadata: public static GET теперь разрешён, проверки Origin/Fetch-Metadata для всех API сохранены. В существующий auth-тест добавлен отказ cross-site GET к данным с Cookie.

Повторное независимое read-only ревью блокеров не выявило. Ограничение ревью: проверены текущие исходники, не полный git diff; ведущий отдельно сравнил lockfile: оставшиеся packages/snapshots не изменены, libc metadata сохранены, удалена только ненужная цепь Ant Design.

Проверки: серверные типы, production build и 12 core-тестов прошли на Node 26.12.0. Живой браузер на изолированном 127.0.0.1:18081 с одноразовыми тестовыми данными: вход, отображение пустого списка, повторное открытие /app/remote, выход, перевод фокуса и пустые localStorage/sessionStorage. Мобильная эмуляция 390px: ширина документа 390px, таблица скроллится в собственном контейнере. Осмотрены desktop/mobile screenshots. Это не проверка реального телефона, TLS или межмашинной сессии.
