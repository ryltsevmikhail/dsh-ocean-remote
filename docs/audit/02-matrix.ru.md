# 02. Матрица пользовательских сценариев

Легенда: **работает** — проверено на реальных машинах в указанных границах; **частично** — подтверждена только часть пути; **отсутствует** — реализации или пользовательского пути нет; **не проверено** — код есть, реального прогона не было; **вне поддержки** — код существует, но форк эту поверхность не адаптировал.

Ссылка «A-» ведёт в [backlog](03-backlog.ru.md). Границы прошлых проверок — в [реестре](00-runtime-evidence.ru.md).

Приоритет строки — приоритет **этого сценария** внутри пробела; приоритет в backlog относится ко всему пробелу и может отличаться в обе стороны (например, M-05 P1 внутри A-17 P2, и M-20 P3 внутри A-42 P2).
